# List of features

## events
_This feature is enabled on HEP Training_

Events are one of the main resources of TeSS. They are defined as face-to-face or online training opportunities that have set start and end times. These primarily take the form of workshops, courses, webinars, etc.; but TeSS also collects information about conferences, meetings and hackathons, as these may also provide opportunities for learning.

## materials
_This feature is enabled on HEP Training_

Materials are one of the main resources of TeSS. They are defined as training resources that can be accessed at any time. These may be in a variety of different formats, including online tutorials, videos, PowerPoint presentations, and so on.

## elearning_materials
_This feature is **not** enabled on HEP Training_

e-Learning materials are a dedicated resource type for self-paced online courses or structured learning modules that can be accessed and completed independently.

## workflows
_This feature is **not** enabled on HEP Training_

Workflows are graphical training tools that represent sequences of learning steps and resources, helping learners visualise the path through a set of training activities.

## collections
_This feature is enabled on HEP Training_

Collections can be seen as "folders" where resources are brought together. They allow curators to group events, materials, and other resources around a common theme or purpose.

## learning_paths
_This feature is enabled on HEP Training_

Learning paths are structured pathways of training resources and topics, designed to guide learners through a coherent sequence of materials and events toward a learning objective.

## content_providers
_This feature is enabled on HEP Training_

Content providers are collectives/organizations which are registered on HEP Training and create learning resources.

## sources
_This feature is **not** enabled on HEP Training_

Sources are configured URLs and ingestion methods that allow content providers to register external feeds or structured data for automatic harvesting into the platform.

## nodes
_This feature is **not** enabled on HEP Training_

Nodes represent organisations or communities (such as ELIXIR nodes) that can appear as separate directory entries or contributors to training resources.

## spaces
_This feature is enabled on HEP Training_

Spaces provide a way to host separate collections or sub-sites within the same TeSS instance, isolating content and branding for different communities or partners.

## subscription
_This feature is enabled on HEP Training_

Subscription allows users to follow queries or resource types and receive notifications about new or updated matching events and materials.

## geocoding
_This feature is **not** enabled on HEP Training_

Geocoding enables automatic address lookup and mapping for event locations, typically translating location data into geographic coordinates.

## bioschemas_testing
_This feature is **not** enabled on HEP Training_

Bioschemas testing enables validation and preview of Bioschemas structured data for resources to help ensure compatibility with TeSS ingestion.

## collection_curation
_This feature is enabled on HEP Training_

Collection curation provides tools to manage and curate the items within a collection, supporting editors in organising and reviewing grouped resources.

## invitation
_This feature is **not** enabled on HEP Training_

Invitation mode restricts new account creation to invited users only, rather than allowing open registration.

## registration
_This feature is enabled on HEP Training_

Registration enables user account creation and login, allowing users to contribute resources, manage subscriptions, and access protected actions.

## login_through_oidc_only
_This feature is **not** enabled on HEP Training_

Login through OIDC only forces authentication to use an OpenID Connect provider exclusively, disabling other login methods.

## user_source_creation
_This feature is enabled on HEP Training_

User source creation allows registered users to create and manage ingestion sources for automatic data harvesting.

## trainers
_This feature is **not** enabled on HEP Training_

Trainers provides a directory of individuals or experts who can be associated with events, materials, or training activities.

## edit_suggestions
_This feature is **not** enabled on HEP Training_

Edit suggestions allows users to propose changes to content that can then be reviewed and accepted by moderators.

## sticky_navbar
_This feature is enabled on HEP Training_

Sticky navbar keeps the site navigation bar fixed at the top of the page while scrolling, improving usability.

## biotools
_This feature is **not** enabled on HEP Training_

BioTools support would allow linking or cataloguing external bioinformatics tools alongside training resources.

## topics
_This feature is **not** enabled on HEP Training_

Topics provide a structured taxonomy of scientific subjects used to classify events, materials, and learning paths.

## operations
_This feature is **not** enabled on HEP Training_

Operations are metadata fields describing scientific methods or activities associated with resources.

## sponsors
_This feature is **not** enabled on HEP Training_

Sponsors capture information about organisations or funding bodies that support an event or resource.

## fairshare
_This feature is **not** enabled on HEP Training_

Fairshare support enables integration with FAIRshare metadata for resource interoperability and reuse.

## county
_This feature is **not** enabled on HEP Training_

County exposes a regional or location field on events, allowing events to be classified by area or region.

## ardc_fields_of_research
_This feature is **not** enabled on HEP Training_

ARDC fields of research allow using Australian Research Data Commons subject codes to classify resources.

## other_types
_This feature is **not** enabled on HEP Training_

Other types permit entering free-form resource categories for material and event types that do not fit standard options.

## subsets
_This feature is **not** enabled on HEP Training_

Subsets allow registering identifiers or DOIs for related resource subsets or parts of a material.

## syllabus
_This feature is **not** enabled on HEP Training_

Syllabus provides a dedicated field to describe the detailed outline or topics covered by a training material.

## approved_editors
_This feature is **not** enabled on HEP Training_

Approved editors lets resource owners specify a list of users who are authorised to edit a content provider or resource.

## address_finder
_This feature is **not** enabled on HEP Training_

Address finder provides an autocomplete or lookup interface for entering event locations accurately.

## visibility
_This feature is **not** enabled on HEP Training_

Visibility controls whether a resource is publicly visible or hidden from the main listings.

## api_system_for_groups
_This feature is enabled on HEP Training_

This is used by HEP Training to link the website to the CERN Group Management System (GMS).

## auto_parse_vars
_This feature is **not** enabled on HEP Training_

Definies which fields TeSS can automaticlly extract from a ressource description.

## controlled_vocabulary_vars
_This feature is **not** enabled on HEP Training_

Used to check the vocabulary variables and seee if the website is understandable for a specific audience.
