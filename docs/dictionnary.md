## The tools

#### Ruby
_[https://www.ruby-lang.org](https://www.ruby-lang.org)_

Ruby is a dynamic, interpreted programming language known for its simplicity and elegant syntax. Used as the foundation for Ruby on Rails and backend development, Ruby emphasizes developer productivity and code readability.

#### Ruby On Rails
_[https://rubyonrails.org](https://rubyonrails.org)_

Ruby on Rails is a full-stack web application framework written in Ruby that provides conventions and tools for rapid development of database-backed web applications. It follows the Model-View-Controller (MVC) pattern and includes built-in tools for common web development tasks.

#### Embedded Ruby
_[https://ruby-doc.org/stdlib/libdoc/erb/rdoc/ERB.html](https://ruby-doc.org/stdlib/libdoc/erb/rdoc/ERB.html)_

Embedded Ruby (ERB) is a templating system that allows you to embed Ruby code within HTML or text documents, enabling dynamic content generation in web applications. ERB tags use `<% %>` syntax to execute Ruby code and `<%= %>` to output values into templates.

#### SCSS
_[https://sass-lang.com](https://sass-lang.com)_

SCSS (Sassy CSS) is a CSS preprocessor that extends CSS with variables, nested rules, mixins, and functions for more maintainable and powerful stylesheets. SCSS compiles to standard CSS and provides advanced features that make styling large projects more efficient.

#### Handlebars.js
_[https://handlebarsjs.com](https://handlebarsjs.com)_

Handlebars.js is a JavaScript templating engine that uses handlebars syntax (`{{...}}`) to generate HTML dynamically with data binding and logic. It provides a simple yet powerful way to create templates that separate presentation logic from application code.

#### Docker
_[https://www.docker.com](https://www.docker.com)_

Docker is a containerization platform that packages applications and dependencies into lightweight, portable containers for consistent deployment across environments. Containers ensure that applications run the same way regardless of where they are deployed, from development to production.

#### Solr
_[https://solr.apache.org](https://solr.apache.org)_

Solr is an open-source search platform built on Apache Lucene, designed for full-text search, analytics, and real-time indexing of large-scale data. It provides fast, relevant search capabilities and is widely used for enterprise search applications.

#### PostgreSQL
_[https://www.postgresql.org](https://www.postgresql.org)_

PostgreSQL is an advanced, open-source relational database management system known for reliability, robustness, and support for complex queries and data types. It includes features like ACID compliance, full-text search, JSON support, and extensibility through custom functions and types.

#### Kubernetes
_[https://kubernetes.io](https://kubernetes.io)_

Kubernetes is an open-source container orchestration platform that automates the deployment, scaling, and management of containerized applications. It handles load balancing, rolling updates, self-healing, and resource management across clusters of machines.

#### OKD / Openshift
_[https://www.okd.io](https://www.okd.io)_

OKD (Origin Kubernetes Distribution) is a Red Hat's open-source Kubernete distribution (open-source version of OpenShift) that extend Kubernetes with developer and operations-focused tools for container platform management. They provide additional features like integrated CI/CD pipelines, developer workflows, and enterprise support.

#### Helm / Helm Chart
_[https://helm.sh](https://helm.sh)_

Helm is a Kubernetes package manager that uses charts (bundles of pre-configured Kubernetes resources) to simplify application deployment and management. Helm charts allow you to define, install, and upgrade complex Kubernetes applications with a single command.

#### OIDC
_[https://openid.net/connect](https://openid.net/connect)_

OIDC (OpenID Connect) is an authentication protocol built on OAuth 2.0 that enables secure user identity verification and single sign-on capabilities. It allows applications to verify user identity and obtain basic user information from an identity provider in a standardized way.
